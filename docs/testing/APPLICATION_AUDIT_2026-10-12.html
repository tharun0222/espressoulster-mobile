Espressoulster application audit

12 October 2026 · Customer, admin and backend agents reviewed the application. No application fixes were made during this audit.

Verification results

  • Backend integration: 62/62 tests passed, including concurrent duplicate checkout and stock overselling protections.
  • Server pricing, ownership, admin authorization, cross-origin protection, upload validation, cancellation/restocking and dummy-payment separation passed.
  • TypeScript check passed. Pricing and subscription tests passed.
  • Payment security test file could not run: it imports hmacHex, which the current module does not export. This is a stale-test coverage gap, not evidence of a payment vulnerability.
  • Live browser: profile opened, menu search produced an empty result and reset restored items. No browser console errors observed in those flows.

Issues found

PriorityFindingEvidence and impact
HighRequests have no timeoutSource review: app/store-app.tsx shared API helper. A stalled request can keep checkout or profile controls busy. Indefinite hanging was not reproduced.
HighRapid cart taps queue savesSource review: app/store-app.tsx cart effect serializes full cart saves; checkout waits for the queue. Slow connections can delay checkout.
MediumCart plus button allows unavailable quantity changesSource review: cart changeQty lacks stock/availability guard. Backend rejects invalid stock at checkout; overselling was not demonstrated.
MediumAdmin history lacks clear payment detailsSource review: app/admin/admin-app.tsx and order collection API. Payment method and discount breakdown are omitted; collection stores fulfilment/payment flow instead of UPI/cash/card.
MediumCustomer order history is incompleteSource review: based on latest 50 global orders, so older customer orders/counts can be absent. Ordered item names and quantities are omitted.
MediumAvoidable database and refresh workOrder listing uses 1 + 2N queries (101 for 50 orders). Periodic user refresh can trigger unchanged cart saves. This is an efficiency concern, not a demonstrated outage.
MediumAdmin availability display can disagree with stockAvailable flag may remain true at inventory zero.
LowOrder filter response race and unclear activity labelsSource review: no latest-response guard on order filtering. Activity log shows raw Action/Target identifiers. Filter race not browser reproduced.
