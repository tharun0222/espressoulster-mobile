# Automatic ingredient nutrition

Admin → Products → Edit → Ingredients & nutrition → Use custom recipe details. Automatic from ingredients is the default for new/legacy drafts. Ingredient name, quantity, unit, addition and removal recalculate fat, fibre, total sugar, protein, carbohydrate and kcal in the editor. Review the estimates and Save product. Explicit manual mode remains available for supplier labels or unlisted foods; existing manual values are preserved.

The server canonicalizes automatic values from ingredient amounts and the same reference table; it does not trust client totals. Customer bootstrap resolves the saved amounts again. Automatic values always retain Estimated status. An ingredient edit clears the review checkbox. Unknown ingredients, unsupported units, malformed amounts and missing quantities clear all totals, rather than displaying a partial serving. Incomplete recipes can be saved as unreviewed but cannot publish reviewed nutrition.

Data: ingredient-nutrition.json is built by scripts/build-ingredient-nutrition.py from the menu's existing audited ingredient references and calculation evidence. There are 224 exact names/explicit spelling aliases. No fuzzy substitution. Portions use grams, kg, ml, litres and known edible piece/slice/leaf weights. Piece weights, volume densities, recipe-range midpoints and standard ingredient proxies are disclosed. Filter-coffee recipes retain their existing assumed 90% brewed yield; discarded beans/grounds are excluded. Compound garnish amounts are counted separately. Totals sum unrounded contributions, then round grams to one decimal and kcal to a whole number.

Compatibility check: 114 of 116 original suggested recipes calculate successfully and agree with previous rounded totals (within 0.1 g and 1 kcal). Two malformed source measurements correctly require an explicit unit/quantity correction before automatic review: Virgin Mojito's unitless Lemon 1/2, and Pesto's Salt 2GM+EE618:E619. Those source entries and existing customer recipes have not been silently changed. Changing them to explicit amounts enables calculation.

Validation: unit tests cover per-ingredient changes, milk volume/density equivalence, foods/flour, pieces, fractions, ranges, garnishes, filter-coffee yield, unknown inputs, authoritative server normalization and legacy manual compatibility. Built Worker integration passes 12 checks including automatic saved totals reaching customer data, a second quantity change, review and incomplete-recipe rejection. Tests use an isolated local Worker/SQLite database; no live products, accounts or subscriptions are changed for testing.
